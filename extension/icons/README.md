# Extension Icons

This folder contains the icons for the **Video Understanding** Chrome Extension.

### Required Icon Sizes & Files:
- **`icon16.png`**: 16×16 px — Used as the favicon for extension pages and toolbar menu.
- **`icon48.png`**: 48×48 px — Used on the extension management page (`chrome://extensions`).
- **`icon128.png`**: 128×128 px — Used during installation and in the Chrome Web Store.

> **Note**: Placeholder icons with a red play button emblem have been pre-generated here so the extension can be loaded immediately as an unpacked extension in Chrome Developer Mode. When you are ready to use your final custom brand icons, replace these three files with your own PNG assets matching the identical filenames and dimensions.
